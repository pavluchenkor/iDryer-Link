# Changelog

Этот файл ведётся на русском языке и фиксирует заметные изменения в прошивке `idryer-link` — модуля связи между iDryerControllerV2 и порталом.

## Типы изменений

- **Добавлено** — для новых функций.
- **Изменено** — для изменений в существующей функциональности.
- **Устарело** — для функций, которые скоро будут удалены.
- **Удалено** — для удалённых на данный момент функций.
- **Исправлено** — для любых исправлений багов.
- **Безопасность** — на случай уязвимостей.

## [3.0.0]

### Добавлено

- **Обновление прошивки по воздуху.** Обновляются оба микроконтроллера: сам Link и iDryerControllerV2, прошивка контроллера идёт через Link. После перезагрузки Link проверяет, что пара версий совместима, и только тогда закрепляет обновление. Не сошлось — откат на прежнюю версию.
- **Привязка к порталу без PIN.** Устройство получает ключ при подключении и адресуется в облаке по собственному идентификатору.
- **Отвязка из портала.** Команда с портала стирает ключ, устройство возвращается в режим ожидания привязки.
- **Температура нагревателя в телеметрии.**

### Изменено

- **Локальная сеть управляет, даже когда облако отключено.** Настройка «Игнор. внеш. команды» блокирует теперь только портал. Приложение в той же сети продолжает управлять сушилкой.
- **Недоступный датчик отдаёт пустое значение,** а не ноль. В портале больше нет ложных нулей.
- Прошивка переведена на общую библиотеку `idryer-core`: связь с порталом, привязка и протокол одинаковы для всех устройств экосистемы.
- **Повышена стабильность связи ESP32-C3 Super Mini.** Мощность Wi-Fi ограничена на платах ESP32-C3 Super Mini.
