# Changelog


Этот файл ведётся на русском языке и фиксирует заметные изменения в прошивке `idryer-link` (ESP-линк сушилки: мост MQTT ↔ UART к контроллеру RP2040).

История до этого файла — в git-тегах (последний выпущенный: `v1.2.1`).

## Типы изменений

- **Добавлено** — для новых функций.
- **Изменено** — для изменений в существующей функциональности.
- **Устарело** — для функций, которые скоро будут удалены.
- **Удалено** — для удалённых на данный момент функций.
- **Исправлено** — для любых исправлений багов.
- **Безопасность** — на случай уязвимостей.

## [Не выпущено]

### Добавлено

- Локальный WS: локальные action-команды метятся флагом `UART_FLAG_LOCAL` — проходят к контроллеру при включённом «Игнор. внеш. команды» (управление из локальной сети сохраняется, облако блокируется).
- Зеркалирование `ignoreExternalCmd` из RP2040 в SDK-гейт.
- Декодирование температуры ТЭНа; распознавание спец-значения «нет данных» (датчик недоступен) — в телеметрию уходит пусто, а не ложное число.
- Парное OTA-обновление обоих МК по воздуху: проксирование прошивки RP2040 по UART; после перезагрузки ESP подтверждает новую прошивку бутлоадеру только после успешного handshake с RP2040 (совместимость пары), иначе бутлоадер откатывает на прежнюю; HW-идентификация платы.
- `MenuPublisher`; веса на отдельном топике; общий header `menu_commands`.
- Ограничение мощности WiFi (8.5 dBm на esp32c3 super-mini).

### Изменено

- Миграция на общий SDK `idryer-core`; `timestamp` в публикации отключён.
